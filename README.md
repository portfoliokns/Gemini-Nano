# このリポジトリの概要
このリポジトリはGemini Nanoを試しに動作させるために作成したWebページになります。

# 事前準備
お使いのGoogle ChromeにGemini Nanoをインストールしておいてください。参考ページ→https://qiita.com/portfoliokns3/items/b7aff65cf62e596fd42e

# 結論として
実際に導入して試したものの、Gemini Nano自体があまり精度がいいとは言えず、現状、どのような活用方法が良いのか全くもって不明のため、このリポジトリは運用を停止しています。あくまで、もしGemini Nanoを使用したい場合にのみ、参考にしてください。
